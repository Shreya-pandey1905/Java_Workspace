# JAVA NIO

It was introduced in java 4 version to overcome the limitation of io package.


Java IO:
1. Java IO reads one stream at a time
2. Follows blocking IO Operations .
3. stream based
4. Slower for large appln.



Java Nio:
1. Can handle multiple channels simultaneously.
2. NIO SUpports non blocking IO operations.
3. Buffer and channel based
4. Designed for high performance appln.

Instead of streams NIO uses :
1. Channels
2. Buffer.
3. Selector

1. Channels:
A channels is like a pipeline through which data flows .

2. Buffer:
Buffer is a temporary memory area where data is stored before your appln process it 

3. Selector
Allows one thread to monitor multiple channels.
