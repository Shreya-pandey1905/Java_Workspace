The repository contains various java related tasks which covers various java topics. 

1) Banking System

Problem Statement:-

A bank wants to automate account management,the system should support account type saving and current and features such as
create account,deposit amount,withdraw amount,transfer money(Just amount is transferred message and balance should be affected),view account details and generate monthly statements

For saving Minimum balance is 1000
For current Minimum Balance is 0

interest rate for saving is 6 percent
interest rate for current is 2 percent

If no transaction is made for last 15 days then account should be marked as dormant and then only deposit amount should be allowed for dormant account(Custom Exceptions) and when after 15 days deposit is performed move  its status to normal.

2) Employee Management System
Develop a console-based Employee Management System using Java Collections and Object-Oriented Programming concepts.

The system should allow users to:

Add a new employee with details such as:
Employee ID
Name
Department
Salary
Date of Joining
Display all employee records.
Update an employee's salary using Employee ID.
Delete an employee record using Employee ID.
Search for an employee by Employee ID.
Find and display the highest-paid employee.
Search employees based on their Date of Joining.
Sort employees by salary in ascending order.
Sort employees by Date of Joining.
Exit the application.

The application should use:

Java Classes and Objects
ArrayList Collection
LocalDate API
Methods and Encapsulation
Lambda Expressions for Sorting
